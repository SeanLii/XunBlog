# About

这是一个面向长期学习的 **Personal AI Knowledge Base**，也是一份公开的学习轨迹。

我本科就读于 Durham University，专业为 Computer Science。目前的学习重点逐渐转向 **Robot Learning / Embodied AI**，尤其是 Action Chunking with Transformers（ACT）。

## 我怎样学习

```text
直觉 → 例子 → 数学 → 模型 → 代码 → 实验 → 重新总结
```

这里不会假装所有理解都从一开始就是正确的。我会尽量保留误解、修正和重新组织概念的过程，因为“为什么没懂”往往和最终答案同样重要。
